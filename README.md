# Rental Warehouse

RimWorld向けに、貸倉庫・貸金庫の経営、預かり資産の防衛、他派閥の金庫襲撃を追加するMODの開発計画です。

**現在は仕様・計画段階です。ゲームで使えるMOD本体・DLL・配布ZIPはまだありません。**

## 予定する遊び

- **経営:** 他派閥の資産を保管し、期間中の料金を受領する。保管容量や契約条件を見て受注する。
- **防衛:** 高危険度の資産を狙う敵から貨物を守り、奪われても持ち去られる前に奪還する。
- **遠征:** ワールド上に独立して存在する他派閥の金庫を襲撃し、突破・略奪・搬出・撤退する。

初期対象はRimWorld 1.7、必須DLCなしを設計目標とします。1.6対応や他MODとの互換性は未検証です。

## インストール

現時点ではインストールできません。リポジトリをModsフォルダーへ置いてもゲーム用MODとして動作しません。実装・検証後、必要ファイルだけを含むZIPと対応ゲームビルド、導入手順を用意する計画です。

既存セーブへの追加を目標としていますが、実機確認は未実施です。契約・サイトがある状態でのMOD途中削除は対応範囲に含めません。
