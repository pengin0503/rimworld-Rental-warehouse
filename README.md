# Rental Warehouse / 貸倉庫

**日本語** | [English](README.en.md)

他派閥の荷物を預かり、襲撃から守り、独立した金庫施設へ遠征するRimWorld 1.7向けMODです。**画面・AI・バランスを含む実ゲームでの動作と他MODとの互換性は未検証**です。

## 導入

RimWorld 1.7.4985と [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) が必要です。DLCは必須ではありません。[Releases](https://github.com/pengin0503/rimworld-Rental-warehouse/releases) の `RentalWarehouse.zip` を展開し、`RentalWarehouse` フォルダをRimWorldの `Mods` に置いて、Harmonyの後に有効化します。

既存セーブに追加できますが、**途中削除は非対応**です。契約や金庫のデータが読み込めなくなるおそれがあります。試す前にバックアップしてください。

## 遊び方

「その他」から受付台を建てて営業を開始します。1〜3日おきに届く依頼を貸倉庫タブで確認・受注し、到着した箱を1日以内に屋内の棚か金庫に収納すると、3〜12日の保管期間が始まります。前払いは期間開始後に、残りの保管料と完了報酬は満期後に回収ポッドで返送すると受け取れます。前払い率は依頼ごとに1回交渉できます。

成功した返却で信頼が上がり、より大きな依頼を受けられます。損失や横領などは信頼を下げます。荷物を狙う専用襲撃があり、箱がマップ外に持ち去られた場合は補償が必要です。預かり箱を開けると横領となり、価値の100%の補償と友好度低下が発生します。未払いは債務となり、新規受注を妨げます。

他派閥の独立金庫にはキャラバンで遠征でき、開錠または破壊して荷物を回収できます。Royalty導入時には、条件を満たすと帝国からの依頼も届きます。

## 設定

MOD設定で依頼の種類、金庫情報、保管料倍率、襲撃規模倍率などを変更できます。変更は新たな依頼や金庫情報に適用され、進行中の契約は変わりません。
