# Rental Warehouse — 要件メモ

更新日: 2026-10-23
状態: 要件整理中。実装仕様の承認・実装完了を意味しない。

## ユーザーが指定した要件

- RimWorld向けの貸倉庫・貸金庫MODを作る。
- 他派閥の資産を預かり、その保管期間中に料金を得る。
- 預かり資産を狙う敵対派閥から資産を守る、クエスト形式の遊びを用意する。
- 倉庫経営と防衛クエストの両方を中心にする。どちらかを付随要素にしない。
- 他派閥にも貸金庫を追加し、プレイヤーが襲撃して資産を奪えるようにする。
- このリポジトリを開発に利用する。

## 検討中の提案（未承認）

### 自コロニー側

- 容量と保管条件を満たす貸倉庫・貸金庫を設置する。
- 低危険度の継続的な保管依頼と、高報酬の防衛依頼を両立する。
- 受注時に期間、報酬、貨物、既知の脅威、補償上限を明示する。
- 専用の封印貨物で所有派閥と契約を管理し、通常の製作・料理・取引による誤消費を防ぐ。
- 定期保管料と返還時の精算を用意し、部分返還にも対応する。
- 敵は貨物の奪取・撤退を目的にする。
- 通常襲撃と契約襲撃による難易度の二重加算を避ける。技術的な実現方法は要検証。

### 他派閥側

- 金庫の管理派閥と預かり資産の所有派閥を区別する。
- 偵察・金庫の突破・運び出し・撤退が襲撃の中心になるようにする。
- 報酬は実際に持ち帰った戦利品とし、資産の二重取得や再訪による無限再生成を防ぐ。
- 外交上の影響は攻撃前に確認できるようにする。

## 次に選ぶ方式

1. 独立した他派閥金庫サイト: 他派閥に属する専用の襲撃先をワールド上に配置する。既存拠点の生成への変更を抑えやすいが、既存の街の中には金庫がない。
2. 既存拠点への金庫組み込み: 派閥拠点を攻撃した際に金庫区画を生成する。街との一体感がある一方、拠点生成MODとの調整が必要。
3. 両方式: 内容は広がるが、生成処理と検証対象が増える。

推奨は1を初期実装とし、2を後から拡張できる構成。ただし方式はまだユーザー未選択。
