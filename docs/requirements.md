# Rental Warehouse — 確定要件

2026-10-23更新。仕様・計画に続き、計画T0～T10の実装を完了（実ゲームでの受入試験は未実施。[検証結果](testing/results-1.7.md)）。

1. 他派閥の資産を貸倉庫・貸金庫に預かり、保管中に料金を得る。
2. 倉庫経営と資産を守る防衛クエストの両方を中心にする。
3. 他派閥にも貸金庫を追加し、プレイヤーが襲撃できるようにする。
4. 他派閥の施設はA方式、既存集落とは独立したワールドサイトとする。
5. 初期版はRimWorld 1.7優先。1.6は別途検証する拡張。
6. 仕様・計画段階では実装しない（当時の指定）。その後のユーザー指示（2026-10-23）により計画どおり実装した。リリース公開は行っていない。
